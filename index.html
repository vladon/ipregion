ipregion

242 checks in five groups: where is your IP, and what does the internet think about it — Google, YouTube, Steam, DNS resolvers and friends included.

Install

$bash -c 'bash <(wget -qO- https://ipregion.top)'

Works from fish and sh, too — the outer bash parses process substitution.

Script needs bash ≥ 4.3 and curl; jq is optional (--json, output files, IP cache).

curl and wget always receive the raw script — this page is shown only to browsers. The script itself is always available at /ipregion.sh.

Quick start

  • ipregion — curated default: GeoIP consensus, messenger transports, DNS health; --full runs everything
  • ipregion -g custom — 189 region checks: messengers, social networks, AI services, streaming, dev hosting
  • ipregion -g dns — 15 reference-based DNS diagnostics: spoofing, interception, DoT/DoH, TTL honesty, rebinding
  • ipregion -g devinfra — GitHub, npm, PyPI, Docker Hub, registries, cert expiry, proxy egress
  • ipregion -g cdn — CDN nodes: YouTube, Cloudflare, Netflix
  • ipregion --watch 300 — monitoring mode: verdict diffs on an interval, optional Telegram push, one-line --dns-summary
  • ipregion --json / --output result.csv — machine-readable output; --fail-on-block exits 1 on red verdicts
  • ipregion --proxy socks5://… — or bind to a specific interface; IPv4 and IPv6 run in parallel
